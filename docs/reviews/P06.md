# P06 evidence: controller port and command-interface design

Date 2026-09-30. Branch `p06-controller` (from `main` `1ee999b`). All
commands ran in the original container (the implementer has no Docker
access). Logs: `log/checks/`, `build/baseline/control/` (ignored by Git).

USER decisions (2026-09-30): the controller port is **strictly faithful and
bit-exact** (no robustness changes); the low-level loop in simulation will
be a **simplified stand-in** (development tool), not ROSflight SIL.

## Claim

`reef_control` `12237b76` (the hardware bundle's pin; same controller math
as the sim pin) is ported to ROS 2 and reproduces the unmodified original
**byte for byte** on every compared value of 21 event streams (20 fixtures
plus one stream from an X3 + REEF run), through the ROS-free core and
through the ROS 2 node. An independent step-wise model written from the
specification reproduces the original with zero difference. The legacy
behaviour that a reviewer would call defects (K1–K13, including a
wrong-sign D term and an anti-windup that never engages when D = 0) is kept
and asserted. The controller is **not yet in any control loop** (P07).
