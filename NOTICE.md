Florida REEF Autonomous Vehicles Lab (AVL) software, one vendored message
package, and one third-party simulation model fetched at setup.

distribution. The evidence behind each licence is recorded below:

The imported Git history of `reef_estimator` contains the lab document
`docs/Estimator_Theory.pdf` (2018) as committed upstream. A third-party paper
(`docs/Partial_Update.pdf`) was removed from every imported commit (P04).

`baseline/` compiles the pinned upstream sources unmodified for reference
testing. They are fetched by `baseline/fetch_sources.sh` into `reference/`,
which Git ignores, and are not redistributed here.
